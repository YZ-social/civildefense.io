The Civil Defense App

A Real App Without an App Store

CivilDefense is a full-featured app in a web page. However, it does not depend on any app store that can block or remove it, or track who downloaded it. You can run it directly from the link, without any installation or signup. You can also choose to install it.

Installation

Installing the app makes it easy to run or remove it from the home screen or dock a hurry.

In addition, Apple mobile devices allow notifications only from installed apps.

Install directly from the app page with one of these browser buttons. Note: Browser button layout changes faster than the AIs get updated!

  • "Add to Home Screen" on mobile devices. Note that this button will not be visible when running inside of another app.
  • "Add to Dock" on desktop Safari.
  • "Install App" on other desktop browsers.

Updates

Regardless of whether it is installed or run from the browser, the CivilDefense app automatically keeps a local copy of itself. It periodically checks the original site for for new versions, but it does not update without asking you. (You might be in the middle of something or have some other reason to stay on the old version.) The app's "CD" button also has a "check for updates" button to check immediately.

Removal

There are no accounts, no database of user activity and preferences, and no data centers. Instead, the list of your current active topics and other data are kept only on your own device. No one can see (or steal, or sell) this information without physical access to your device.

To remove this local data on an installed app, simply delete or uninstall the app. The operating system will delete all the local data

To remove it from the browser, use the "Wipe all CivilDefense data" link under the app's "CD" button. On mobile Safari, Apple keeps the browser data separate from the app data, and each must be removed separately. Other platforms share the data between app and browser.
